Core Capabilities

What json-renderers-run-options Delivers

Three foundational enhancement pipelines engineered to plug cleanly into any declarative component blueprint.

Search Pipeline

Search Bar Integration

Injects responsive search headers, search labels, helper text, and filter input boxes above tabular or card structures.

options.showSearch: true
  • Mounts to header container / table root
  • Configured via optionDefs.search
  • Verified with JSONPath mount checks
Serial Pipeline

Serial Numbering Column

Prepends serial count headers (<th>#</th>) and serial row counter cells dynamically without mutating raw data rows.

options.showSerial: true (or .serial)
  • Targets thead row and each tbody row
  • Preserves collection column indices
  • Configured via optionDefs.serial
Options Pipeline

Row Actions Column

Appends an action column featuring customizable button groups (View, Edit, Delete, Details) into table rows.

options.showOptions: true (or .options)
  • Injects <th>Actions</th> and button cells
  • Fully customizable action templates
  • Configured via optionDefs.options
Developer Experience

Simple, Clean & Expressive

Transform your component blueprint in one call. Pass your base AST, specify which features you want, and provide definition instructions.

Standard ESM Import

Use modern ECMAScript module imports in Node.js 18+ and modern browsers.

Safe Path Filtering (V2)

Uses jsonpathly to ensure instructions only run against valid target destinations.

Built for the KeshavSoft Ecosystem

Pairs natively with declarative-definitions, spec-repo, and json-instruction-single.

import runOptions from "json-renderers-run-options";
import definitions from "declarative-definitions";
import { spec } from "spec-repo";

// 1. Obtain a clone of your base component AST
const base = structuredClone(spec.tableSimple);

// 2. Run declarative optional features
const finalAst = runOptions({
    base,
    options: {
        showSearch: true,   // Injects search bar
        showSerial: true,   // Injects '#' column
        showOptions: true   // Injects action buttons
    },
    optionDefs: definitions.table.simple.options,
    showLog: false          // Enable debug logging
});

console.log(finalAst);
