How to Use the Downloaded min.js

1. Plain HTML Script Tag

Place min.js in your project directory and load it directly:

<script type="module" src="./min.js"></script>
2. In-Browser Module Import
<script type="module">
  import runOptions from "./min.js";

  const enhancedAst = runOptions({
    base: myTableAst,
    options: { showSearch: true, showSerial: true, showOptions: true },
    optionDefs: myOptionDefinitions
  });
  console.log(enhancedAst);
</script>
3. Enterprise / Air-Gapped Environments

The downloaded .zip package contains everything needed to operate inside isolated intranets without external CDN dependencies.
