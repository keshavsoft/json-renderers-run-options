Technical Documentation

API Guide & Reference

Complete signature specifications, parameter contracts, import variations, and debug options for runOptions.

runOptions(config)

Default Export

Executes conditional feature instructions against a base JSON AST and returns the mutated AST. 

import runOptions from "json-renderers-run-options";

const mutatedAst = runOptions({
    base,
    options,
    optionDefs,
    showLog
});
Parameters (config Object)
Field Type Default Description
base Object required The root JSON DOM AST to be modified. If falsy, returns base unmodified.
options Object {} Map of feature boolean flags enabling/disabling specific options.
optionDefs Object {} Instruction blueprints dictionary defining search, serial, and options rules.
showLog Boolean false When set to true, logs execution targets and single instructions to the console.

Supported Options & Aliases

runOptions accommodates both modern descriptive flags and concise shorthand keys:

Feature Primary Key Alias Key Matching Definition
Search Bar options.showSearch — optionDefs.search
Serial Number Column options.showSerial options.serial optionDefs.serial
Row Action Buttons options.showOptions options.options optionDefs.options

Import Variations

1. Default ESM Import (Recommended V2)
import runOptions from "json-renderers-run-options";
2. Named ESM Import (V2)
import { runOptions } from "json-renderers-run-options";
3. Direct Path Version Imports
// Direct Latest V2
import { runOptions } from "json-renderers-run-options/src/v2/index.js";

// Legacy V1 (data-role matching)
import { runOptions as runOptionsV1 } from "json-renderers-run-options/src/v1/index.js";
4. Browser CDN Import via ESM
<script type="module">
  import runOptions from "https://cdn.jsdelivr.net/npm/json-renderers-run-options@1.2.1/src/index.js";
  // Ready to use in browser!
</script>
